# Cloud Security

This module records hands-on AWS Config and GuardDuty work completed in `us-east-1`. It separates preventive and detective controls from the underlying VPC networking implementation.

## Modules

- [AWS Config compliance and remediation](aws-config/README.md)
- [GuardDuty detection and investigation](guardduty/README.md)

## What this demonstrates

- Continuous evaluation of resource configuration against a security rule.
- Identification and remediation of an SSH-exposure compliance finding.
- Generation and interpretation of AWS-provided GuardDuty sample findings.
- Clear distinction between simulated detection evidence and a real production incident.
